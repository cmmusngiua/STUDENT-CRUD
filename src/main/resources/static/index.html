Backend Setup & Help

Ensure your Spring Boot backend & PostgreSQL are ready

  1. 1. PostgreSQL Database

    Verify PostgreSQL service is running and database db_user exists on port 5432:

    CREATE DATABASE db_user;
  2. 2. Run Spring Boot Backend

    In IntelliJ IDEA, run StudentApplication.java, or run via terminal:

    .\mvnw.cmd spring-boot:run
  3. 3. Open the Frontend

    Open in your browser: http://localhost:8080
